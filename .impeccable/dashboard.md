# Operations dashboard

Mode: Operate

## Direction contract

**Thesis** — Show the movement of consignments and the work that needs attention in the same view.

**Own world** — Deep navy navigation, a cool light working surface, Inter, tabular figures, and blue for primary actions. Status colors are shared between charts, tables, and shipment history.

**Story** — Choose a branch and date range, read current volume and delivery workload, then open a recent LR or create a booking.

**First viewport** — A persistent navigation rail and search bar frame four metrics, a daily booking trend, a linked status breakdown, and the opening rows of the shipment register. New Booking sits alongside the date control.

**Form** — Code-led dashboard using the supplied palette and navigation. Its signature interaction is a shared status breakdown that opens the matching shipment queue. Seed: none (unavailable).

**Finish** — unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
